# دليل المبتدئين إلى Pure React: ريأكت الخام من تحت الصفر 🧬

عندما يبدأ أغلب الناس تعلم React، يُفاجَأون بأدوات معقدة: (شاشات سوداء، أوامر Terminal، مجلدات عملاقة، وملفات لا تنتهي). فيصيبهم الإحباط ويظنون أن ريأكت لغة صعبة جداً!

لكن الحقيقة السحرية هي: **React في أصلها مجرد ملف جافا سكريبت بسيط جداً يمكنك وضعه داخل أي صفحة HTML عادية!**

وهذا ما نطلق عليه **Pure React (ريأكت الصافية/الخام)**: أن نستخدم ريأكت بدون أي أدوات مساعدة، وبدون برامج تثبيت، لنفهم كيف تعمل الماكينة من الداخل قبل أن يغطيها الديكور الخارجي.

---

## 1. الكود الذي أمامنا (الصورة الكاملة)

هذا هو أبسط تطبيق ريأكت يمكن كتابته على وجه الأرض:

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>hello react</title>
  </head>
  <body>
    <!-- 1. المكان الذي سيعيش فيه التطبيق -->
    <div id="root"></div>

    <!-- 2. استدعاء مكتبات ريأكت من الإنترنت -->
    <script src="https://unpkg.com/react@18/umd/react.development.js"></script>
    <script src="https://unpkg.com/react-dom@18/umd/react-dom.development.js"></script>

    <!-- 3. كود ريأكت الخاص بنا -->
    <script>
      function App() {
        return React.createElement("h1", null, "Hello React");
      }

      const root = ReactDOM.createRoot(document.getElementById("root"));
      root.render(React.createElement(App));
    </script>
  </body>
</html>
```

---

## 2. تفكيك الكود بالتفصيل الممل (تشريح خطوة بخطوة)

دعنا نأخذ كل جزء من الكود ونشرح ماذا يفعل ولماذا وُضع هنا:

### أولاً: مسرح الجريمة (`<div id="root"></div>`) 🎭

- المتصفح في الأصل يعرض صفحة HTML فارغة.
- هذا السطر عبارة عن صندوق فارغ (حاوية) يحمل المعرف `id="root"` (وكلمة root تعني **الجذر** أو الأساس).
- **فائدته:** نحن نقول لـ React: "هذا هو مكانك المخصص، كل موقعنا المستقبلي وأزراره وصوره ستُبنى بالكامل داخل هذا الـ `<div>` الصغير، ولا تلمسي أي شيء خارجه!".

---

### ثانياً: استدعاء العقلين المدبرين (سكريبتات الـ CDN) 🧠👷‍♂️

لاحظ أننا قمنا باستدعاء ملفين منفصلين تماماً لـ React:

```html
<script src="https://unpkg.com/react@18/umd/react.development.js"></script>
<script src="https://unpkg.com/react-dom@18/umd/react-dom.development.js"></script>
```

لماذا هما ملفان وليسا ملفاً واحداً؟ إليك التشبيه:

1. **الملف الأول (`react.development.js`): هو (المهندس المعماري) 📐**
   - هذا هو قلب ريأكت النقي.
   - مسؤوليته فقط: التفكير، حساب المنطق، إدارة المكونات والبيانات، وتصميم شكل الصفحة على الورق في الذاكرة.
   - العجيب أن هذا الملف **لا يعرف شيئاً إطلاقاً عن متصفحات الويب!** هو فقط يفكر في العناصر.

2. **الملف الثاني (`react-dom.development.js`): هو (عامل البناء) 🔨**
   - هذا هو المترجم والوسيط بين المهندس (React) وبين أرض الواقع (متصفح الإنترنت DOM).
   - يأخذ الرسوم الهندسية من ريأكت ويذهب للمتصفح ليقول له: "اصنع لي هنا عنصر `<h1>` واكتب داخله كذا".
     _(لهذا السبب، ريأكت يمكنها استخدام مهندسها نفسه مع عامل بناء آخر لصنع تطبيقات الموبايل مثل React Native!)_

> **ملاحظة:** الرابط `unpkg.com` يسمى **CDN**، وهو ببساطة خادم خارجي على الإنترنت نحمّل منه هذه الملفات مباشرة بدون الحاجة لتنزيلها على جهازنا.

---

### ثالثاً: المكون الأول في حياتك (`function App()`) 🧱

```javascript
function App() {
  return React.createElement("h1", null, "Hello React");
}
```

- في عالم ريأكت: **المكون (Component) هو مجرد دالة جافا سكريبت عادية جداً (Function)!**
- الشرط الوحيد: أن تُرجع هذه الدالة عنصراً من عناصر ريأكت لكي يُرسم على الشاشة.
- اسم الدالة هنا `App`، وتبدأ بحرف كبير (Capital) ليميز ريأكت أنها مكوّن وليست دالة عادية.

---

### رابعاً: قلب ريأكت السري (`React.createElement`) 🪄

هذا هو أهم أمر ستراه في عالم ريأكت:

```javascript
React.createElement("h1", null, "Hello React");
```

هذه الدالة تأخذ 3 أشياء أساسية بالترتيب:

1. **الوسيط الأول (نوع العنصر):** `"h1"` (أخبرناه أننا نريد إنشاء عنوان كبير).
2. **الوسيط الثاني (الخصائص Props):** `null` (حالياً لا نريد إعطاءه أي خصائص مثل لون أو كلاس أو معرف `id`، لذا كتبنا `null` أي "لا شيء").
3. **الوسيط الثالث (المحتوى الداخلي Children):** `"Hello React"` (النص الذي سيعيش داخل هذا العنوان).

**النتيجة في النهاية:** هذا الأمر يقوم بتصنيع كائن جافا سكريبت يمثل هذا العنصر: `<h1>Hello React</h1>`.

---

### خامساً: توصيل الأسلاك وبدء العرض (`createRoot` & `render`) ⚡

```javascript
// 1. تحديد نقطة الانطلاق
const root = ReactDOM.createRoot(document.getElementById("root"));

// 2. أمر الرسم والعرض
root.render(React.createElement(App));
```

1. **`document.getElementById("root")`:** كود جافا سكريبت عادي للوصول إلى الصندوق الفارغ الذي جهزناه في البداية.
2. **`ReactDOM.createRoot(...)`:** ميزة ظهرت في الإصدار React 18، معناها: "يا عامل البناء (ReactDOM)، اجعل هذا الصندوق هو نقطة البداية والجذر لكل عملياتك القادمة".
3. **`root.render(...)`:** كلمة render تعني (اعرض/ارسم). نحن نقول له: خذ هذا المكون المسمى `App`، وقم برسمه وحقنه داخل صندوق الـ root في صفحة المتصفح الحقيقية!

---

## 3. لماذا لا نكتب ريأكت بهذه الطريقة دائماً؟ 🤔

لو أردت عمل صفحة حقيقية تحتوي على `div`، وبداخله `ul`، وبداخلها 5 عناصر `li`، ستضطر لكتابة كود بشع مليء بالأقواس المتداخلة هكذا:

```javascript
React.createElement(
  "div",
  null,
  React.createElement(
    "ul",
    null,
    React.createElement("li", null, "عنصر 1"),
    React.createElement("li", null, "عنصر 2"),
  ),
);
```

هذا الكود مقرف جداً في القراءة والتعديل!  
لذلك اخترع مطورو ريأكت ما يسمى بـ **JSX**، وهو اختصار يسمح لنا بكتابة كود يشبه الـ HTML مباشرة هكذا:

```jsx
<div>
  <ul>
    <li>عنصر 1</li>
    <li>عنصر 2</li>
  </ul>
</div>
```

ولكن تذكر دائماً: **كل كود JSX تكتبه، يقوم المتصفح في الخفاء بتحويله إلى دالة `React.createElement` تماماً كما تعلمت في هذا الملف اليوم!**

## 4. جدول المصطلحات البرمجية التقنية (دليلك المبسط)

| المصطلح التقني (Term)                     | الشرح المبسط بالعربي                                                                                           |
| :---------------------------------------- | :------------------------------------------------------------------------------------------------------------- |
| **Pure React**                            | استخدام مكتبة ريأكت بأبسط وأصفى صورها دون الحاجة لأي أدوات بناء أو بيئة عمل خارجية.                            |
| **CDN (Content Delivery Network)**        | شبكة سيرفرات سريعة على الإنترنت تُستخدم لتحميل ملفات البرمجة الجاهزة مباشرة دون تنزيلها على جهازك.             |
| **React Core (`react.js`)**               | النواة الأساسية لريأكت، وهي المسؤولة عن التفكير وإدارة المكونات وحسابات الذاكرة فقط.                           |
| **ReactDOM (`react-dom.js`)**             | الجزء المسؤول عن تحويل أفكار وتصميمات ريأكت وتطبيقها فعلياً داخل متصفح الويب.                                  |
| **Root Element (عنصر الجذر)**             | عنصر الـ `<div>` الرئيسي في ملف الـ HTML الذي تُحقن داخله شجرة تطبيق ريأكت بالكامل.                            |
| **`React.createElement()`**               | الدالة الأصلية في ريأكت المسؤولة عن بناء أي عنصر في الصفحة، وتأخذ (نوع العنصر، خصائصه، ومحتواه).               |
| **Component (مُكوّن)**                    | دالة جافا سكريبت تُرجع واجهة مستخدم (أو عنصر ريأكت) لكي يظهر على الشاشة.                                       |
| **Props (الخصائص)**                       | المدخلات والصفات التي نمررها للعنصر (مثل الكلاسات أو المعرفات)، ويُعبر عنها بالوسيط الثاني في `createElement`. |
| **`createRoot()`**                        | دالة حديثة في React 18 تنشئ نقطة التحكم الرئيسية لإدارة الصفحة وعرض محتواها.                                   |
| **`render()`**                            | أمر التنفيذ الفعلي الذي يحوّل عناصر ريأكت المرسومة في الذاكرة إلى عناصر HTML حقيقية يراها المستخدم.            |
| **Development Build (`.development.js`)** | نسخة خاصة بالمبرمجين أثناء التطوير، تكون أكبر حجماً لكنها تقدم رسائل أخطاء واضحة جداً لمساعدتك في حل المشاكل.  |

# 🚀 إعداد مشروع React جديد: دليلك الشامل من الصفر

# (Setting Up a New React Project: The Options)

أهلاً بك في عالم **React**! إذا كانت هذه هي المرة الأولى التي تسمع فيها عن هذا الموضوع، أو تشعر بالحيرة من كثرة الأدوات والمصطلحات، فلا تقلق أبداً. هذا الدليل كُتب خصيصاً ليشرح لك كل شيء خطوة بخطوة ومن البداية تماماً.

---

## 🧭 أولاً: لماذا لا نفتح ملف HTML عادي ونكتب React مباشرة؟

عندما بدأت تعلم الويب، كنت تنشئ ملفاً باسم `index.html` وتفتحه في المتصفح، وانتهى الأمر!
فلماذا نحتاج إلى "أدوات إعداد" (Setup Tools) مع React؟

1. **كتابة كود حديث (JSX):** في React، نكتب كوداً يجمع بين HTML و JavaScript يسمى **JSX**. المتصفحات العادية لا تفهم JSX مباشرة، لذا نحتاج إلى أدوات تترجمه إلى JavaScript عادي يفهمه المتصفح.
2. **تقسيم الكود (Modules):** React تعتمد على تقسيم الموقع إلى أجزاء صغيرة ومستقلة تسمى **Components** (مكونات)، كل مكون في ملف منفصل. نحتاج أداة تجمع كل هذه الملفات معاً في ملف نهائي واحد بسرعة.
3. **التحديث المباشر أثناء التطوير (Hot Reloading):** بمجرد أن تعدل سطراً في الكود، سترى النتيجة فوراً في المتصفح دون الحاجة للضغط على زر Refresh.

لذلك، ابتكر المبرمجون أدوات تسمى **Build Tools / Frameworks** تقوم بكل هذا السحر بالنيابة عنك وتجهّز لك المشروع بضغطة زر.

---

## 🛠️ ثانياً: الأدوات التي يجب تثبيتها قبل أن تبدأ (المتطلبات)

قبل كتابة أي أمر، يجب أن يكون على جهازك:

1. **محرر أكواد (Code Editor):** وأفضل خيار للمبتدئين والمحترفين هو **VS Code** (Visual Studio Code).
2. **Node.js:** هو بيئة تتيح تشغيل كود JavaScript على جهازك الشخصي (خارج المتصفح).
   - حمله مجاناً من الموقع الرسمي: [nodejs.org](https://nodejs.org) (اختر نسخة **LTS** لأنها الأكثر استقراراً).
   - عند تثبيت Node.js، سيتم تلقائياً تثبيت أداة اسمها **npm** (مدير الحزم) التي سنستخدمها لتحميل React.

> 💡 **للتأكد من نجاح التثبيت:** افتح موجه الأوامر (Terminal أو CMD) واكتب:
>
> ```bash
> node -v
> npm -v
> ```
>
> إذا ظهرت لك أرقام إصدارات، فأنت جاهز 100%!

## 🗂️ ثالثاً: الخيارات المتاحة لإنشاء مشروع React

توصي وثائق React الرسمية بطريقتين أساسيتين اليوم، مع وجود خيار قديم يجب أن تعرفه حتى تتجنبه. إليك التفاصيل:

---

### الخيار رقم 1: استخدام Vite (الخيار الأفضل والأسهل للمبتدئين) ⭐

- **ما هو؟** أداة بناء فائقة السرعة، تم إنشاؤها لتجعل تجربة التطوير مريحة وخفيفة جداً.
- **يناسبك لو:** كنت تريد تعلم أساسيات React، أو بناء تطبيق واجهة أمامية (Front-end SPA) بسيط إلى متوسط مثل (موقع شخصي، لوحة تحكم، تطبيق مهام To-Do).
- **المميزات:**
  - خفيف جداً على الجهاز.
  - سريع البرق في التشغيل وفي حفظ التعديلات.
  - لا يحتوي على تعقيدات تقنية في البداية.

#### 📝 خطوات تشغيل Vite:

1. افتح الـ Terminal واكتب الأمر التالي:

   ```bash
   npm create vite@latest my-react-app
   ```

2. سيسألك عن التقنية: اختر بالسهم **React**.
3. سيسألك عن اللغة: اختر **JavaScript** (أو TypeScript إذا كنت تعلمه).
4. ادخل إلى مجلد المشروع ونفذ الأوامر:

   ```bash
   cd my-react-app
   npm install
   npm run dev
   ```

5. سيعطيك رابطاً محلياً مثل `http://localhost:5173`، افتحه في المتصفح ومبروك! مشروعك يعمل.

---

### الخيار رقم 2: استخدام Next.js (إطار العمل الشامل والاحترافي) 🏢

- **ما هو؟** إطار عمل كامل مبني فوق React (يسمى Framework). طورته شركة Vercel وهو الخيار الموصى به رسمياً في وثائق React للمشاريع الكبيرة.
- **يناسبك لو:** تريد بناء موقع تجاري، متجر إلكتروني، مدونة تحتاج إلى أن تظهر في نتائج بحث Google بقوة (SEO)، أو موقع يحتاج إلى كود Server و Database معاً (Full-Stack).
- **المميزات:**
  - يوفر ميزة **الرندرة على الخادم (SSR)**، مما يجعل محركات البحث تقرأ صفحاتك بسهولة.
  - يوفر نظام تنقل بين الصفحات (Routing) تلقائياً بمجرد إنشاء ملفات جديدة.
  - جاهز للإنتاج فوراً دون الحاجة لتركيب مكتبات خارجية كثيرة.

#### 📝 خطوات تشغيل Next.js:

1. افتح الـ Terminal واكتب الأمر التالي:

   ```bash
   npx create-next-app@latest my-next-app
   ```

2. سيطرح عليك عدة أسئلة (استخدم TypeScript؟ استخدم Tailwind؟.. إلخ): للمبتدئ، يمكنك الموافقة على الخيارات الافتراضية بالضغط على Enter لكل سؤال.
3. ادخل للمجلد وشغّل المشروع:

   ```bash
   cd my-next-app
   npm run dev
   ```

4. افتح المتصفح على: `http://localhost:3000`.

### الخيار القديم: Create React App (CRA) - ⚠️ تجنبه الآن!

- **ما هو؟** كانت هذه هي الأداة الرسمية لسنوات طويلة لإنشاء مشاريع React (`npx create-react-app`).
- **لماذا يجب أن تتجنبه؟**
  - توقف الفريق المطور عن صيانته وتحديثه.
  - أصبح بطيئاً جداً ويعتمد على حزم قديمة وبها ثغرات أمنية.
  - فريق React نفسه أزال التوصية به واستبدله بـ **Vite** و **Next.js**.

## 📚 قاموس المصطلحات البرمجية (Glossary)

إليك جدول بأهم المصطلحات التي ستسمعها طوال رحلتك في React مشروحة بأبسط لغة ممكنة:

| المصطلح (Term)                          | الشرح المبسط بالعربي                                                                                                                         |
| :-------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------- |
| **React**                               | مكتبة برمجية طورتها شركة Facebook، وظيفتها بناء واجهات المستخدم (UI) التفاعلية بطريقة سهلة وسريعة.                                           |
| **Component (المكون)**                  | هو حجر الأساس في React؛ قطعة كود صغيرة مسؤولة عن جزء من الشاشة (مثل: زر، قائمة منسدلة، نافذة منبثقة) يمكنك إعادة استخدامها عدة مرات.         |
| **JSX**                                 | صيغة كتابة تسمح لك بكتابة عناصر مثل HTML مباشرة داخل ملف الـ JavaScript (مثل `<h1>Hello</h1>` داخل الكود).                                   |
| **Node.js**                             | بيئة تتيح تشغيل كود JavaScript على جهازك والكمبيوتر نفسه دون الحاجة لفتح المتصفح.                                                            |
| **npm (Node Package Manager)**          | متجر رقمي عملاق يحتوي على مئات الآلاف من الأكواد والمكتبات الجاهزة التي تستطيع تحميلها واستخدامها في مشروعك مجاناً.                          |
| **CLI / Terminal (الطرفية)**            | الشاشة السوداء (أو شاشة الأوامر) التي تكتب فيها أوامر نصية ليقوم الكمبيوتر بتنفيذها (مثل إنشاء مجلد أو تشغيل مشروع).                         |
| **Bundler (مُجمّع الحزم)**              | أداة وظيفتها جمع مئات ملفات الكود والصور التي كتبتها وتجهيزها وضغطها لتصبح ملفات قليلة خفيفة يفهمها المتصفح.                                 |
| **Vite**                                | أداة بناء وتطوير حديثة وسريعة جداً تُستخدم لإنشاء وتجهيز مشاريع الويب (مثل React).                                                           |
| **Framework (إطار عمل)**                | مثل Next.js؛ يوفر لك هيكلاً وقواعد جاهزة لتنظيم المشروع كاملاً (صفحات، اتصال بالسيرفر، حماية) وليس فقط مجرد الواجهة.                         |
| **SPA (Single Page Application)**       | تطبيق صفحة واحدة؛ موقع لا يقوم بإعادة تحميل الصفحة كاملة كلما نقرت على رابط، بل يغير المحتوى بسلاسة وسرعة (مثل تطبيق فيسبوك).                |
| **SSR (Server-Side Rendering)**         | تقنية تعني أن السيرفر هو من يقوم بإنشاء وتجهيز صفحة الويب أولاً ثم يرسلها للمتصفح كاملة، وهي ميزة ممتازة لتحسين ظهور الموقع في Google (SEO). |
| **Dependencies (الاعتماديات/المكتبات)** | ملفات وأكواد كتبها مطورون آخرون وقمت بتحميلها داخل مشروعك لتعتمد عليها في إنجاز مهمة معينة (مثل مكتبة للأيقونات أو الرسوم البيانية).         |
| **Hot Module Replacement (HMR)**        | ميزة سحرية تجعل المتصفح يحدّث الجزء الذي غيرته فقط في الكود بدون إعادة تحميل الصفحة بالكامل، وتعمل في أجزاء من الثانية.                      |

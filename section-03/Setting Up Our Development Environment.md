# الدليل الشامل لفهم اختصارات الأكواد (VS Code Global Snippets) للمبتدئين 🚀

أهلاً بك يا صديقي! إذا فتحت هذا الملف، فغالباً رأيت المدرب يكتب حرفين أو ثلاثة في برنامج **VS Code** وفجأة ظهرت له عشرات أسطر الكود في رمشة عين كأنه ساحر!  
ثم فتح لك ملفاً غريباً يحتوي على أقواس ونصوص وقال لك: _"هنا نعدل الـ Global Snippets"_.

لا تقلق إطلاقاً! في هذا الدليل سنشرح الموضوع من تحت الصفر خطوة بخطوة، لكي تفهم ما يحدث خلف الكواليس بدلاً من مجرد النسخ واللصق.

---

## 1. التشبيه الواقعي: ما هو الـ Snippet أصلاً؟ 📱

تخيل هاتفك الذكي:
بدلاً من أن تكتب لصديقك كل مرة: **"السلام عليكم ورحمة الله وبركاته، أنا في الطريق إليك وسأصل خلال خمس دقائق"**...  
قمت بعمل اختصار في لوحة المفاتيح: بمجرد أن تكتب حرفي **"سل"** وتضغط مسافة، الهاتف يكتب الجملة كاملة بدلاً منك!

**الـ Snippet في البرمجة هو هذا الاختصار تماماً:**

> كلمة صغيرة تكتبها (مثل `cl`) ← تضغط زر `Tab` ← يقوم برنامج VS Code بتوليد كود كامل جاهز بدلاً منك (مثل `console.log()`).

---

## 2. ما معنى كلمة "Global" Snippet؟ 🌍

عندما تفتح في برنامج VS Code:  
`Manage (علامة الترس ⚙️) → Snippets → New Global Snippets file`

كلمة **Global (عام / عالمي)** تعني:

- هذا الاختصار لا يعيش داخل مشروعك الحالي فقط!
- هو اختصار مسجل في برنامج VS Code نفسه على جهازك بالكامل.
- إذا فتحت مشروعاً اليوم، أو مشروعاً بعد سنتين، ستجد نفس الاختصارات تعمل معك في كل مكان دون الحاجة لإعادة ضبطها.

---

## 3. تشريح ملف الـ Snippets (فهم الكود المكتوب)

الملف الذي ظهر لك ينتهي بامتداد `.code-snippets`، وهو مكتوب بصيغة **JSON** (طريقة لترتيب البيانات تشبه القواميس).

دعنا نأخذ مثال المدرب الشهير ونفككه قطعة قطعة:

```json
"Print to console": {
  "prefix": "cl",
  "scope": "javascript,typescript,javascriptreact,typescriptreact",
  "body": [
    "console.log($1)"
  ],
  "description": "console.log"
}
```

### أ) `"Print to console"` (اسم الاختصار)

- مجرد اسم تعريفي لك وللبرنامج، لا يؤثر في كتابة الكود إطلاقاً.
- سمّه ما شئت (مثل: `"طِباعة في الكونسول"` أو `"My Log"`).

### ب) `"prefix": "cl"` (الزناد أو الاختصار) 🎯

- **هذا هو أهم سطر!**
- الحروف التي ستكتبها بيدك داخل المحرر لكي يقترح عليك إكمال الكود.
- هنا اخترنا `cl`، بمجرد كتابتها والضغط على زر `Tab` ينفجر الكود تلقائياً.

### ج) `"scope"` (نطاق العمل وأين يشتغل؟) 🛑

- تحدد به أنواع الملفات المسموح لهذا الاختصار بالظهور داخلها.
- أنت لا تريد اختصار جافا سكريبت أن يظهر لك وأنت تكتب ملف نصي عادي أو كود HTML خالص!
- الأنواع الشهيرة:
  - `javascript` → لملفات `.js`
  - `typescript` → لملفات `.ts`
  - `javascriptreact` → لملفات الـ React العادية `.jsx`
  - `typescriptreact` → لملفات الـ React مع تايب سكريبت `.tsx`

> ⚠️ **تنبيه مهم جداً:** المدرب غالباً ينسى إضافة `typescriptreact`، فإذا كنت تعمل React مع TypeScript مستقبلاً لن يعمل معك الاختصار إلا إذا أضفتها في الـ scope!

### د) `"body"` (الكود الفعلي الذي سيظهر) 💻

- هذا هو الكود الحقيقي الذي سيقوم VS Code بكتابته نيابة عنك.
- يوضع بين أقواس مربعة `[ ]`، وكل سطر كود يوضع بين علامات تنصيص `" "`.

### هـ) `"description"` (الوصف التوضيحي)

- نص صغير يظهر في القائمة المنسدلة ليذكرك ماذا يفعل هذا الاختصار قبل أن تضغط عليه.

---

## 4. الرموز السحرية داخل الـ Body (سر الاحتراف) 🪄

### 1. الـ Tab Stops: `$1` و `$2` و `$0`

عندما يكتب الكود تلقائياً، أين ترغب أن يقف مؤشر الفأرة (Cursor) لتبدأ الكتابة فوراً؟

- **`$1`:** المكان الأول الذي سيقف فيه المؤشر فور توليد الكود.
- **`$2`:** المكان الثاني الذي سينتقل له المؤشر بمجرد ضغطك على زر `Tab`.
- **`$0`:** **المحطة الأخيرة!** المكان الذي سيستقر فيه المؤشر بعدما تنتهي من إدخال كل البيانات.

### 2. القيم الافتراضية: `${1:قيمة_افتراضية}`

- إذا أردت أن يضع البرنامج كلمة افتراضية قابلة للتعديل.
- مثال: `${1:User}` تعني: اكتب كلمة User افتراضياً، ولكن إذا ضغط المستخدم على الكيبورد، امسحها واكتب ما يكتبه هو.

### 3. المتغيرات الديناميكية: `${TM_FILENAME_BASE}` 🌟

- هذا المتغير يقرأ **اسم الملف الحالي** تلقائياً من الويندوز/الماك!
- فإذا كنت داخل ملف اسمه `Navbar.jsx`، سيقوم هذا المتغير بكتابة كلمة `Navbar` بدلاً منك دون أن تلمس الكيبورد!

### 4. التكرار التلقائي للأسماء (Mirroring):

لو كتبت `$1` في ثلاثة أماكن مختلفة داخل الكود، بمجرد أن تغير الكلمة في المكان الأول، ستتغير في المكانين الآخرين في نفس اللحظة تلقائياً!

### 5. علامة `\t` (المسافات والترتيب)

- ترمز لزر `Tab` (مسافة بادئة Indentation) حتى يخرج الكود منسقاً ومرتباً وليس مكدساً على اليسار.

## 5. المثال الذهبي: عمل React Component بضغطة زر ⚡

بدلاً من كتابة هيكل الـ React يدوياً في كل ملف جديد، نصنع اختصاراً اسمه `rfc`:

```json
"React Functional Component": {
  "prefix": "rfc",
  "scope": "javascriptreact,typescriptreact",
  "body": [
    "function ${1:${TM_FILENAME_BASE}}() {",
    "\treturn (",
    "\t\t<div>",
    "\t\t\t$0",
    "\t\t</div>",
    "\t)",
    "}",
    "",
    "export default ${1:${TM_FILENAME_BASE}}"
  ],
  "description": "ينشئ مكوّن ريأكت باسم الملف تلقائياً"
}
```

### ماذا سيحدث هنا بالسحر؟

1. لو أنشأت ملفاً اسمه `ProductCard.jsx`.
2. كتبت داخله: `rfc` ثم ضغطت `Tab`.
3. البرنامج تلقائياً سيكتب:
   - اسم الدالة: `ProductCard`.
   - التصدير بالأسفل: `export default ProductCard`.
   - سيضع لك المؤشر مباشرة في منتصف الـ `<div>` عند علامة `$0` لتكتب محتوى تصميمك فوراً!

---

## 6. نصيحة ذهبية: لا تُفرط في استخدام الـ Snippets! 🧠

الـ Snippets أداة إنتاجية (Productivity Tool) وليست مهارة برمجية بحد ذاتها:

- **استخدمها لـ:** الكود المكرر الممل الذي تحفظه عن ظهر قلب (Boilerplate).
- **لا تستخدمها لـ:** الهروب من فهم أساسيات اللغة. يجب أولاً أن تفهم كيف يُبنى الـ Component ولماذا نكتب `export default` قبل أن تترك الاختصار يكتبها لك!
- لا تجمع 100 اختصار على جهازك فتنساها جميعاً؛ 3 إلى 5 اختصارات للحاجات اليومية كافية جداً.

---

## 7. جدول المصطلحات البرمجية التقنية (مرجعك الشامل)

| المصطلح البرمجي (Term)                 | الشرح المبسط بالعربي                                                                              |
| :------------------------------------- | :------------------------------------------------------------------------------------------------ |
| **Snippet (مقتطف كود)**                | قطعة كود مجهزة مسبقاً يتم استدعاؤها باختصار نصي صغير لتوفير وقت الكتابة.                          |
| **Global Snippets**                    | اختصارات عامة يتم حفظها على مستوى برنامج VS Code نفسه لتعمل في جميع مشاريعك.                      |
| **Project-level Snippets**             | اختصارات خاصة بمشروع واحد فقط لا تعمل خارجه.                                                      |
| **Boilerplate Code**                   | كود روتيني مكرر يتوجب عليك كتابته في بداية كل ملف جديد دون تغيير يذكر في شكله.                    |
| **Prefix (البادئة / الزناد)**          | الكلمة أو الحروف المختصرة التي تكتبها بيدك ليقترح عليك المحرر الكود (مثل `cl` أو `rfc`).          |
| **Scope (النطاق)**                     | تحديد أنواع الملفات أو اللغات البرمجية التي يُسمح للاختصار بالعمل داخلها.                         |
| **Body (جسم الكود)**                   | الكود البرمجي الفعلي الذي سيتم توليده وإدراجه داخل الصفحة.                                        |
| **Tab Stop**                           | نقاط توقف يحددها الرمز `$`؛ تجعل المؤشر يقفز إليها تباعاً كلما ضغطت زر `Tab`.                     |
| **Placeholder (العنصر النائب)**        | نص افتراضي يضعه المحرر لك مؤقتاً داخل الكود لتعديله أو استبداله بسهولة.                           |
| **Variable (`${...}`)**                | متغير يوفره VS Code لجلب معلومات حية من جهازك تلقائياً (مثل اسم الملف أو التاريخ).                |
| **`${TM_FILENAME_BASE}`**              | متغير داخلي يقرأ اسم الملف المفتوح حالياً بدون امتداده.                                           |
| **Indentation (المسافة البادئة `\t`)** | إزاحة الأسطر البرمجية للداخل لتوضيح الهيكل البصري وجعل الكود مقروءاً ومرتباً.                     |
| **JSON Object**                        | طريقة قياسية لكتابة البيانات والخصائص تبدأ بـ `{` وتنتهي بـ `}` تُبنى على مبدأ (المفتاح والقيمة). |
| **Productivity Tool**                  | أداة أو ميزة هدفها تسريع كتابة الكود وتوفير مجهود المطور دون تغيير طريقة عمل البرنامج نفسه.       |
| **Language ID**                        | الاسم التقني الذي يتعرف به VS Code على نوع لغة الملف (مثل: `javascriptreact` لملفات الـ JSX).     |
